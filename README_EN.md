## 📖 About

Osynk is a OneDrive file sync tool for Android, built with Flutter.

**🎯 This project was created for learning purposes**, practicing Flutter state management, OAuth authentication flows, file I/O, Microsoft Graph API integration, and related technologies.

## ✨ Features

- 🔐 Microsoft OneDrive OAuth login
- 🔄 Three sync modes: bidirectional / upload mirror / download mirror
- 🎨 Material 3

## 🛠️ Development

```bash
flutter pub get          # 📥 Install dependencies
flutter run              # ▶️ Run
flutter analyze          # 🔍 Static analysis
flutter build apk        # 📦 Build APK
```
